← Sounds

Easiest way (about 20 seconds per sound)

  1. Tap Add next to a sound → the Shortcuts app opens → tap Add Shortcut.
    If nothing opens, tap ⬇︎ File instead → Download → Safari's ⬇︎ Downloads → tap the file → Add Shortcut.
  2. In Shortcuts, long-press the new tile → Share → Add to Home Screen.
  3. Optional: tap the small icon there → Choose Photo to use this sound's icon (tap 🖼 Icon below → long-press → Save to Photos first). Rename if you like → Add.

Tap the new Home Screen icon → it plays instantly. No app screen opens, it works offline (the sound is built into the shortcut), and it plays even with the silent switch on (it uses media volume). iOS shows a small “running” bubble at the top for a moment.

Build one yourself instead (no download needed)
  1. Tap Copy next to a sound to copy its link.
  2. Open Shortcuts → + → search Get Contents of URL → tap it → tap the blue URL field → Paste.
  3. Search Play Sound → tap it (it plays the “Contents of URL” automatically).
  4. Tap the name at the top → Rename (e.g. “Vine Boom”) → Done.
  5. Same name menu → Add to Home Screen → set icon/name → Add.
  6. More sounds: long-press the shortcut → Duplicate → open the copy → paste a different link → rename → Add to Home Screen.

This version streams the sound, so it needs internet. For offline: download the .mp3 (long-press link → Download Linked File), then use the File action (pick the mp3) instead of Get Contents of URL.

Shortcut files are signed so iOS will import them; each one only contains its sound and a “Play Sound” step.
